# DESIGN.md library

Curated from VoltAgent/awesome-design-md (MIT, see LICENSE). Each file in `library/` describes one
product's visual language: colour tokens, type scale, spacing, radii, components, motion and voice.

Included: airtable, cal, claude, cursor, figma, framer, intercom, linear.app, mercury, miro, notion,
pinterest, posthog, raycast, resend, sentry, spotify, stripe, supabase, superhuman, vercel, warp, webflow.
The upstream repo has about 80 more (`git clone --depth 1 https://github.com/VoltAgent/awesome-design-md`).

## How to use

1. Pick one to three references that fit the brief. For a creator workspace (an app people work in all
   day), the closest are linear.app, notion, raycast, cal, superhuman and posthog.
2. Read only those files. Take principles (proportions, how the accent is used, density, type ratios),
   not their brand: never copy a logo, wordmark, exact palette or name.
3. Write the result into the project's own `DESIGN.md` at the repo root, so every later change follows
   one documented system. Keep it current when the system changes.
